# Visual task labels

Use this compact visual contract automatically for non-trivial work. Icons support the text; color never carries meaning alone.

- `🎯 P — Outcome`: observable result.
- `🚧 U — Bottleneck`: one real constraint.
- `🛡️ L — Rule / Gate`: boundary controlling action.
- `🛠️ R — Resolution`: smallest complete change.
- `✅ N — Proof + Next`: owner, artifact, authoritative check.

Task line: `📁 TASK = verb + observable outcome · 👤 OWNER = one accountable person · 🔎 PROOF = authoritative readback`.

Weight line always includes text labels: `🟩 CONTINUE`, `🟨 CHECKPOINT_AND_SPLIT`, `🟥 STOP_AND_CLOSEOUT`, or `⚪ UNAVAILABLE`.
