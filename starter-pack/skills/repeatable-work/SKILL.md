# Repeatable Work

Use this when the same task has appeared more than once or when the user asks for a reusable process.

Define:

- input and source of truth;
- desired artifact;
- constraints and actions requiring human approval;
- short execution steps;
- acceptance check and proof;
- owner and next numbered action.

Keep the workflow narrow. Do not add tools, files, automations, or permissions that the outcome does not require.
