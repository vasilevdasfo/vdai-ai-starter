# SOS1 — Deep

Use only when the user explicitly says `SOS1`. Run ProblemOS, one strong task-shaped route, relevant domain Skills, a critic pass, revision, and acceptance proof. Use at most seven relevant specialists. Return `depth_level=DEEP`. All external and irreversible gates remain unchanged.

## Required phases

- Frame: exact outcome, artifact, constraints, owner, gate, and proof.
- Build: one primary route shaped to the task, using only relevant domain Skills.
- Critique: one independent adversarial pass focused on facts, logic, interpretation, risk, and the opposite hypothesis.
- Revise: repair every material objection or record the consciously accepted trade-off.
- Prove: run the acceptance check on the authoritative artifact or runtime surface.

Do not simulate seven specialists when fewer are sufficient. Do not turn the critic into ornamental commentary; its findings must change the result, the evidence requirement, or the verdict.

Return `depth_level=DEEP`, selected Skills, critic findings, changes made, proof, unresolved objections, gate, and next owner.
