# Numbered Next

Use numbers only for selectable next actions.

- Start a new topic at `1`.
- Continue the same topic with the next unused positive number.
- Use `0` for all currently visible safe actions.
- Mark one recommended route and explain why.
- Never hide publishing, sending, payment, credentials, deletion, legal, reputation, or other irreversible action inside `0`.

Before showing the route, state the observable result or exact blocker.
